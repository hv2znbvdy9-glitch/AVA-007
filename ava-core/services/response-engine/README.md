# Response Engine

Automated response orchestration service for AVA CORE.

## Planned Functionality

- Execute `allowed_actions` on assets in response to alerts
- Coordinate multi-step response sequences (e.g. alert → safe shutdown → notify)
- Support manual approval gates for critical actions
- Log all actions taken with audit trail
- Integration with external notification systems (email, webhook, SMS)

## Status

🚧 **Planned** – IP blocking via Windows Firewall is implemented in the edge agent MVP.
