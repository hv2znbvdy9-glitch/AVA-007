# Detection Engine

Rule-based and ML-powered anomaly detection service for AVA CORE.

## Planned Functionality

- Evaluate telemetry against static thresholds (implemented in edge agent MVP)
- Baseline learning from historical telemetry data
- ML model inference for multi-variate anomaly detection
- Correlation of alerts across assets (e.g. simultaneous temperature and current spikes)
- Rule engine with configurable YAML/JSON rule definitions

## Status

🚧 **Planned** – static threshold detection is implemented in the edge agent MVP.
