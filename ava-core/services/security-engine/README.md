# Security Engine

Security policy evaluation service for AVA CORE.

## Planned Functionality

- Define and enforce security policies for OT/IT network segments
- Evaluate whether observed connections conform to a zero-trust network policy
- Integrate with Windows Firewall, network switches and SDN controllers
- Generate compliance reports and policy violation alerts
- Role-based access control for AVA configuration changes

## Status

🚧 **Planned** – basic IP blocking is implemented in the edge agent MVP.
