# Camera Connector

Integrates image capture from industrial cameras or IP cameras to support visual asset identification and change detection.

## Planned Functionality

- Periodic image capture from USB or IP cameras
- Region-of-interest cropping mapped to asset `photo_refs`
- Anomaly detection via image diff (visual change alerts)
- Integration with digital twin mapper for asset localisation

## Status

🚧 **Planned** – not yet implemented.
